# Excess Baggage Calculator

## About the Project
Excess Baggage Calculator is an Android application designed to help users calculate additional baggage charges when their luggage exceeds the permitted weight limit.

## Features
- Calculate excess baggage charges.
- Calculate an additional 8% service tax.
- Display the total payment amount.
- Simple and user-friendly interface.

## Technologies Used
- Java
- Android Studio
- XML
